- `fishing/FishingController.ts`：竿尖世界坐标按缩放重算。
- `core/Game.ts`：拖拽命中区按放大后的猫尺寸更新。

## 交互/难度/去池塘
用户反馈：① 右键不要退出，改为右下角 X 退出按钮；② 钓鱼难度太大——"浮标开局居中不往下掉，鱼往下掉就失去"，疑似 bug 或数值；③ 不要池塘，蓝色一个圈难看。

### ① 退出按钮
- `core/Input.ts`：新增 `quitHitTest` / `onQuit` 回调与指针位置跟踪（`pointerX/pointerY`），`pointerdown` 命中退出按钮即退出、不再触发钓鱼/拖拽。
- `core/Game.ts`：去掉右键退出（右键仅 `preventDefault`）；用 `T.QUIT_BTN` 接 `quitHitTest/onQuit`；`frame()` 每帧算悬停写入 `view.quitHover`。
- `render/PetView.ts`：新增 `drawQuitButton()`（右下角圆形暗底 + 亮描边 X，悬停变红高亮）。
- `shared/constants.ts`：新增 `QUIT_BTN: {x:436,y:536,r:15}`。

### ② 难度诊断（结论：非 bug，是数值设计）
- 用 `scripts/difficulty-sim.ts`（Fish+CatchBar+ProgressBar 无头模拟，"鱼在绿条中心上方就按住"的人类近似策略）量化：
  - 原版：低难度鱼 100%，但 `dart/floater/sinker` 及高难度（狗鱼/河豚/章鱼/鱼王）几乎 0%；**开局对齐后河豚、章鱼 0%→100%**，证实"鱼开局在绿条外、进度瞬间狂掉"是主因。
- 修复：
  - `states/HookState.ts`：进入小游戏时把绿条对齐到鱼中心（`bar.pos = clamp(fish.pos - bar.size/2)`），开局鱼必在绿条内。
  - `shared/constants.ts` 调参：`BAR_SIZE_BASE 96→124`；鱼速 `FISH_SPEED_BASE 60→46`、`FISH_SPEED_PER_DIFF 1.1→0.65`；`DART_AMP_BASE 60→52`、`DART_AMP_PER_DIFF 1.0→0.55`；`FISH_SPRING_K 3.5→3.0`、`FISH_DAMPING 5→4.5`；`SINKER/FLOATER_ACCEL 70→52`；进度 `GAIN 0.12→0.16`、`DRAIN_BASE 0.18→0.11`、`PROGRESS_INITIAL 0.3→0.35`。
  - 调参后模拟：各鱼捕获率均可达 100%；鱼王(难度110)鱼速 117/s 仍超绿条上限 96/s，真人难完美追踪、保留梯度。
- 结论同步给用户：物理无 bug（按住上升/松开下落、弹簧追踪都对），是数值偏难 + 开局不对齐。

### ③ 去池塘
- `render/PetView.ts`：删除 `drawPond/drawLilyPad/drawReed`（脚本按行区间删除），不再画蓝色椭圆水体；保留钓线（暗描边+亮高光）、浮标、涟漪环、水花，悬空垂钓。
- `shared/constants.ts`：移除 `POND_CX/CY/RX/RY`。

## 紧凑化 + 拖拽/退出/难度/文字 四联动
用户反馈：① lev 徽章仍太远、桌宠整体面积太大；② 右下角退出按钮太大；③ 拖拽不顺滑有重影；④ 桌面截图后自动退出（要明确点击才退出）；⑤ 钓鱼偏简单、要难度随机性并说明公式；⑥ 钓到鱼结算窗字迹不清。

### 修复
- **紧凑化**（`shared/constants.ts` + `render/PetView.ts`）：窗口 `VIEW 340×390`、`PLAYER_SCALE 3.0→2.6`、`PLAYER_X 238/FOOT_Y 342`、抛竿落点 `CAST 95~160/300~345`；捕获条 `BAR 58×176, BAR_TOP 42`；lev 徽章改为**跟随人物右上角**（`playerX+CAT_DW/2+4`）；结算弹窗窗口居中、`w=min(250,VIEW_W-16)` 自适应；提示文字左移避开退出按钮；退出按钮 `QUIT_BTN {x:320,y:370,r:10}`（半径 15→10）。
- **拖拽重影**（`core/Game.ts` + `index.html`）：弃用逐帧 IPC `setPosition`，改为在人物身区放 `-webkit-app-region:drag` 透明层（`#drag-handle`）交给操作系统原生拖动，顺滑无重影；移除 Input 手动拖拽命中/回调与 HTML 右下角常驻提示条（会与 X 重叠）。
- **截图自动退出**（`core/Input.ts`）：确认退出唯一路径是点击 X（原 `pointerdown` 即退）。改为**完整点击**（按下+松开都在按钮上）才退出；并加**冷静期**：失焦(`blur`)或被遮盖(`visibilitychange hidden`)后 1400ms 内的退出点击忽略——挡掉截图通知/全屏覆盖层被 alwaysOnTop 窗口挡到时的误点。
- **难度随机性**（`fishing/entities/Fish.ts` + `states/MinigameState.ts`）：`Fish.diff = clamp(基础难度 × rand(0.85,1.15), 10, 110)`，鱼速/变向幅度/变向频率/进度流失全部改用 `diff`。公式见下。
- **结算窗文字**（`render/PetView.ts`）：新增带深色描边的 `text()` helper，中文标题/品质/提示改用描边矢量字并增号（18→20、12→13），透明背景下也清晰。

### 当前钓鱼难度公式（有效难度 d = 基础难度 × rand(0.85,1.15)，clamp 10~110）
- 绿条：高 = `124 + 8×等级`；按住上升加速度 720、松开重力 288、限速 ±96、触底反弹 30；开局对齐到鱼中心。
- 鱼速上限：`46 + 0.65×d`（d=110 → 117 > 绿条限速 96，鱼王难完美追踪）。
- 变向：目标幅度 `52 + 0.55×d`（dart ×(1+2d/100)、smooth ×0.7）；变向间隔 `lerp(2600,380,(d-15)/95) × 行为系数 × rand(0.7,1.3)`。
- 运动：弹簧追踪 `accel=(target-pos)×3.0`，`vel += (accel + bias - vel)×4.5×dt`；sinker 向下偏置 +52、floater 向上偏置 −52。
- 进度：初始 0.35；条内 `+0.16/s`；条外 `−0.11×(0.55+0.85d/110)/s`。

### MAX 抛竿
