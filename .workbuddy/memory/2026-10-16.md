## 第8期：点击区域扩大到正方形 + 修复"不能蓄力/不能持续按住"bug
用户反馈：①希望小人身上连带等级条下方近似正方形区域都可点击（不只小人身体）②点击变手掌但无法蓄力、钓鱼中无法持续按住（bug）。
- **②根因（关键）**：第7期用 `#drag-handle` 一层 `pointer-events` 覆盖在人物区，它吞掉了 `pointerdown`，导致 canvas 的 `Input` 收不到按下 → `held` 永远 false → 蓄力/收线全失效。手掌光标是手柄的 `grab`，但点击根本没进 Input。
- **修复（去掉吞噬层，改窗口级监听）**：
  - `Game.ts`：删除 `drag-handle` 元素及其 pointer 监听。改为在 `window` 上监听 pet 区拖拽：
    - `pointerdown`：仅当 `controller.stateName==='idle'` 且落在 `inPetBody()` 正方形内 → 标记 `petDown`，记录起点（**不**拦截事件，让 canvas/Input 照常收到按下→可蓄力/收线）。

    - `pointerup/cancel`：`petMoved=false` 时什么都不做（Input 已正常收到按下/松开→钓鱼照常）；否则复位 `dragActive`。
  - **关键设计**：钓鱼进行中（charge/wait/hook/minigame/result）pet 区按下不会触发拖窗逻辑（`stateName!=='idle'` 提前 return），完全交给 Input → **钓鱼中可正常蓄力/持续按住收线**。
  - `Input.ts`：新增 `cancelHeld()`（撤销未松开的 mouse 源，回退一次 press 沿）；删除废弃的 `simulateTap()`。
  - `FishingController.ts`：新增 `abort()`（非 idle 时复位到 idle 并清理 castPower/maxCast/fish/result）。

- **光标**：`frame()` 里按指针位置动态设光标——空闲态在正方形热区显示 `grab`（手掌），拖窗中 `grabbing`，其余 `pointer`。

## 第9期：消除拖拽重影 + 绿条放大覆盖鱼
