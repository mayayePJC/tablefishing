## 拖拽重影修复 + 弹窗点击外部关闭（commit 435b749）

用户反馈三段：①拖拽重影；②点击范围 OK；③呼出菜单后面板外任意点关闭。

**根因**：上一轮（efb754b）为兼容"点一下钓 / 按住拖"用了手写 IPC `setPosition` 拖窗，透明分层窗上 `setPosition` 必留拖影。

**修复方案（最终、已验证）**：
- 身体区 `#pet-hit` 改回原生 `app-region:drag`（OS 合成器移窗，无重影），`movable:true` 已在主窗口。
- "点一下钓"：`mousedown` 起钓鱼蓄力（**不 preventDefault**，否则阻止系统拖窗），`mouseup` 由 Input 收尾抛竿。
- "按住拖"：OS 原生移窗；主进程 `win.on('move')` 在 `bodyDragging` 态转发 `pet-body-moved` → 渲染进程 `abortBodyDrag()` 取消蓄力 + `controller.abort()`，避免松手误抛竿。新增 IPC：`pet-body-drag-begin/end`、`pet-body-moved`；移除旧的 `pet-drag`。
- 弹窗点击外部关闭：`Game.onDocPointerDown`（document 捕获阶段）统一处理，判定抽到 `src/renderer/core/overlayClose.ts` 的 `shouldCloseOverlay`（纯函数，可单测）。

**测试**：新增 `scripts/overlay-close-test.ts`（7/7 通过）+ 既有 `scripts/gesture-test.ts`（10/10）；`npm test` 已串起两条；`tsc --noEmit` 通过；`npm run dist` 离线打包便携版+NSIS 均签名成功（10:14 产物）。
