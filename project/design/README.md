# Fishing Codex · 设计稿索引

> 既有设计图为 **AI 像素参考图**（已去右下角水印），用途是锁定「该长什么样」。
> 当前新增的蜡笔小新、樱桃小丸子、皮卡丘、流川枫、哆啦A梦姿态表为 **代码绘制资产的真实烘焙图**，直接来自游戏使用的 `SpriteFactory`，用于检查角色识别、姿态、透明像素与持竿位置。
> 按 `../设计规范.md` 红线：**AI 参考图不直接入游戏**，开发需在 24×40 / 12×8 网格上按图重绘。
> 每张图都与 `src/renderer/shared/characters.ts`、`fishing/data/fishTable.ts`、`shared/rods.ts` 的数据一一对应；同源姿态表也不作为第二套精灵素材加载。

## 统一画风基准
- 星露谷式像素：粗暗描边 `#241a12`、方块像素无抗锯齿、无渐变、暖亮手工感、单图 ≤32 色。
- 角色一律**面朝左**，人物在窗口右侧、钓线向左侧抛出。
- 背景为暖浅灰（设计稿底），游戏内为透明。

## 素材生产约定
- AI 参考图生成：`ImageGen`（约 5–10 信用点/张），**串行或分目录**生成，避免同秒时间戳同名覆盖。
- 同源代码姿态表：运行 `node scripts/run-character.mjs --render`，生成当前新增 5 角色的姿态表及 `outputs/v0.1.4-qa/` 联系表；同时验证 10 角色的七姿态、竿尖、眨眼、存档恢复与旧角色 ID 迁移，新增角色检查 32 色上限和剪影差异。
- 当前角色列表以 v0.1.4 为准：前五项实际显示名为 ABIGAIL、HARRY、威利、柯罗拉、矮人（ID 依次为 `farmer/cat/frog/penguin/wizard`）；后五项使用上表角色。表内“农夫/橘猫/青蛙/企鹅/巫师”描述的是资产类型，不替代界面显示名。旧 v0.1.3 参考资产和验收记录属于历史资料，不再作为当前图鉴条目。
- 角色识别优先：小新与小丸子不能只靠红衣区分；皮卡丘保留长耳和闪电尾；流川枫保留 11 号球衣；哆啦A梦保留白脸、红鼻与铃铛。七姿态均保持面朝左、脚底稳定，图鉴直接展示同源待机帧。
- 去水印：`_tools/clean_watermark.py`（取水印上方像素条带下延，保留 UI 面板纹理）。
- 废稿归档在 `_raw/`，不计入正式稿。

## 后续新增内容

## v0.1.5 BGM 菜单与声音设计

> 本节保留 v0.1.5 历史设计与验收口径。v0.1.6 已改为独立音乐面板；原“设置列内展开、显示路径、手动刷新”要求由下一节替代，不作为当前 UI 预期。

- BGM 继续在 188px 设置列内原位展开，长曲名使用完整可访问名称/title，音乐条目在菜单内部滚动；目录路径可换行，不能撑宽 340×390 窗口或遮挡隐身、自启和退出入口。
- 显示实际 BGM 文件夹路径与“刷新音乐列表”，打开音乐菜单会自动重扫。目录曲目只有播放/停止，导入副本才显示“移除”；刷新期间、空目录、读取失败和文件已移走均使用可读中文状态，不用实现细节代替操作提示。
- 内置区改为“环境音”，只列“森林雨”“机场”，分别对应 `forest-rain` 与 `airport`。使用预制立体声 Ogg 循环，菜单不再显示旧春夏秋合成曲，也不将环境音标成星露谷原版录音。用户自己的已购 OST 通过目录或导入入口播放。
- 本地曲目和环境音共享唯一当前选择及统一静音，状态高亮、停止按钮、BGM 入口短标签和重启恢复要一致。旧曲目失效显示停止后的真实状态，不能保留已删除文件的播放高亮。
- 本节是设计验收要求；实际菜单截图、自动回归结果和听感结论分别由本轮测试/发布记录确认，旧版本截图不能作为本轮目录菜单证据。

## v0.1.6 独立音乐面板、隐身快捷键与目录约定

> 本节保留 v0.1.6 设计记录。隐身热键及设置菜单说明的当前要求由文末 v0.1.8 节覆盖。

- 设置中的 BGM 入口打开独立羊皮纸音乐面板，并收起设置菜单；标题“音乐”和关闭按钮固定，曲目区内部滚动，底部保留“＋ 添加音乐”。当前面板宽 284px、高 330px，适配 340×390 窗口，不扩大桌宠窗口。
- 内置区标题为“自然与远方”，列出“森林雨”“机场”；本地目录曲目和导入副本统一放在“我的音乐”。当前曲目有清楚的选中/停止状态，长曲名能换行并有完整可访问名称/title，空库使用简短引导。
- 曲库在启动及每次打开面板时自动扫描。**当前 UI 不显示目录路径、技术性曲库说明或手动刷新按钮**；扫描错误用可读中文状态呈现，重新打开面板可重试。目录曲目仍无移除按钮，导入副本保留“移除”，所有源文件只读。
- 独立面板打开时隐藏人物与升级庆祝等画面层，整窗保持交互；关闭、点击面板外或再次点右下菜单均可收起。菜单 DOM、hover、原生窗口 region 继续共用 32×32 按钮几何，不被面板或透明人物层覆盖。
- 设置隐身旁显示 **Ctrl+Shift+H · 全局隐身** 及真实注册状态。未聚焦时快捷键仍有效，长按不反复切换；冲突时显示“全局快捷键不可用，可点击隐身切换”，不显示虚假的可用提示。隐身隐藏人物/等级与其热区，保留菜单入口。
- 机场候机为 120 秒立体声循环：约 0.15 秒出现提示音，约 **1.15 秒开始中文播报**，第二次约 61.15 秒；此后跨循环保持 60 秒间隔。森林雨保留柔和雨床和自然变化，不用循环末尾淡出制造明显静音缝。音轨时间以未暂停播放进度计，静音后恢复不从头播报。
- 工作区工程统一移入 `project/`；本索引位于 `project/design/README.md`，上述相对源码路径仍相对工程根。根目录保留无控制台启动器 `fishing-codex.exe`、最新安装包 `FishingCat-Setup-0.1.6.exe` 与私人 `BGM/`，真实游戏程序和 DLL 同放 `project/runtime/`。本地已购 OST、缓存和生成中间文件不上传仓库。
- 新版界面截图、真实音轨解码/波形验证、主观聆听、全局热键和原生窗口输入分别记录结果；v0.1.5 截图与35/90秒播报记录仅为历史，不能用作 v0.1.6 通过证据。宝箱/收益外观仍以 `../plan/宝箱与鱼类收益系统方案.md` 为规划，不能在当前界面宣称已可购买或领奖。

## v0.1.7 快捷键与设置菜单精简

> 本节为历史设计。v0.1.7 的全局 H 会占用其它应用的输入，已由下一节的焦点内快捷键替代。

- **H** 单键全局切换隐身，不需要 Ctrl 或 Shift；桌宠失去焦点时仍可用，长按只触发一次。**M** 保持在桌宠获得键盘输入时切换静音。
- 设置菜单的“隐身”只保留名称与开关状态，删除下方独立快捷键说明行，不为快捷键或注册状态增加菜单高度。H 注册冲突仅通过按钮悬停 title 提示，菜单按钮仍可切换隐身。
- 本轮当前安装包为 `FishingCat-Setup-0.1.7.exe`；根启动器、工程与 `BGM/` 目录约定沿用 v0.1.6。

## v0.1.8 快捷键按窗口焦点生效

- **H 隐身、M 静音**仅在桌宠窗口获得键盘焦点时生效；长按只切换一次。切换到其它应用、桌宠失焦或只悬停桌宠时，不处理这些快捷键，也不占用其它应用的字母输入。
- 输入框、文本区域、可编辑元素以及输入法组合期间，H、M 作为文字输入，不切换隐身或静音。失焦时清理按键保持状态，回到桌宠后可正常再次操作。
- 移除原生全局 H 注册及相关注册状态提示，不以低层键盘钩子或后台轮询代替。隐身菜单仍只显示名称与开关，不增加快捷键说明行或菜单高度。
- 当前安装包为 `FishingCat-Setup-0.1.8.exe`；隐身热区、根启动器、工程与 `BGM/` 目录约定继续沿用。
- 验收分别覆盖前端焦点与编辑状态、跨应用 H 正常输入、无原生 H 注册和实际安装版本；未经实际执行的项目不标记通过。

## 当前功能增量：BGM 一级入口与健康提醒

- BGM 是工具菜单一级按钮，点击后打开独立音乐面板；设置二级菜单不再承载 BGM 曲目，避免菜单层级和曲名挤在同一列。面板只保留环境音、BGM 文件夹曲目、导入和停止操作，不显示目录路径或“刷新文件夹”等技术操作。
- 提醒开关位于设置二级菜单。喝水和久坐提醒默认关闭，开启后分别按 60 分钟和 50 分钟计时；到时使用居中的暖纸木框 `alertdialog`，按钮和面板外点击均可关闭，弹窗期间隐藏人物交互层。
- 文字提示固定为“大姐姐，该喝水啦”和“大姐姐，站起来走走吧”。只有蜡笔小新尝试读取本地授权语音 `audio/shinchan-water.ogg`、`audio/shinchan-break.ogg`；素材缺失时仍完整显示文字，其它角色保持静音。
- 鱼在轨道上下沿保留内缩目标区，触边立即反向并换内侧目标；视觉层继续使用同一轨道边界和绿条坐标，避免改变小游戏命中契约。
- 角色渲染沿用统一 24×40 像素网格，通过轮廓环境光遮蔽、待机阴影、专属高光和抛竿尾迹增加层次；不改变角色命中区或竿尖映射。
