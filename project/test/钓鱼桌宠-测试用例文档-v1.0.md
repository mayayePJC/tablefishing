## 1. 基本信息

- **项目名称**：Fishing Codex · 钓鱼桌宠（星露谷风格透明可拖拽桌宠）
- **被测版本**：v0.1.3（Tauri v2 唯一壳，`src-tauri/`，fishing-codex.exe + 同目录 WebView2Loader.dll；Electron 分支已于 2026-10-19 整体移除；本文保留旧版本历史测试记录）
- **模块范围**：钓鱼核心流程、小游戏、结算与成长、七姿态动画、手势与窗口交互、点击穿透、三面板弹窗、存档、音效、Tauri IPC 桥接、构建冒烟
- **测试类型**：功能测试 / 状态转换测试 / 边界值测试 / 等价类测试 / 错误推测 / 兼容性测试 / 冒烟测试
- **设计日期**：2026-10-19（2026-10-19 晚间修订：数值重调 / 三面板拆分 / 七姿态落地）
- **测试环境**：Windows 10/11 x64；Node ≥22（`node --experimental-strip-types`）；Tauri v2 + 系统 WebView2；本地 localStorage 可用；Edge headless + CDP（无头浏览器自动化链）
- **设计基准**：`plan/PRD.md`、`src/renderer/shared/constants.ts`（调参集中地 `T`）、`src/renderer/fishing/**`、`src-tauri/src/lib.rs`、`设计规范.md`、`plan/数值重调方案.md`
- **执行方式说明**：
  - **自动化·纯逻辑/桥接**（可立即执行）：`npm test`（150 断言：gesture 20 + overlay-close 7 + BGM 52 + interaction 71）与 `npm run typecheck`；Rust 当前 11 测试覆盖释放/坐标转换。
  - **自动化·无头浏览器**（Edge headless + CDP，`out-test/*.cjs`）：`cdp-pose2.cjs`（七姿态 13 断言）、`cdp-pickers.cjs`（三面板 25 断言）、`cdp-e2e.cjs`（主闭环 26 断言）、`cdp-e2e2.cjs`（垃圾/升级/设置 11 断言）、`cdp-drive.cjs`（逐状态截图体检）。启动方式：Edge `--remote-debugging-port=9222` + `python -m http.server 8901`（服务 `out/renderer`）。
  - **自动化·难度量化**：`node scripts/run-balance.mjs`（esbuild 打包 `scripts/balance.ts`，驱动真实 `FishingController`，人因参数：反应 220ms + ±30 单位瞄准误差，跑 Lv0/5/10 三档，文末三门禁断言）。
  - **手动 GUI**（需真机点测）：所有涉及原生拖窗、点击穿透、托盘、音频、透明窗渲染的用例。沙箱内无法验证，交付时必须标注「已验证编译 / 单测 / 无头探针 / 打包，未实机点测」。
  - ⚠ **历史脚本状态**：`scripts/difficulty-sim.ts` / `.cjs` 为旧版遗留（常量快照过时），**量化难度只认 `run-balance.mjs`**，勿用旧脚本数据验收。

### 2.2 业务规则

|--------|----------|----------|
| BR-01 | 点击范围：窗口顶部 30px 空白带不触发钓鱼；人物身体（含 lev 徽章区）= 钓鱼 + 拖窗；工具按钮 = 菜单；钓鱼会话进行中整窗可交互；空闲时非热点区域点击穿透 | 钓鱼 / 手势 / 穿透 |
| BR-02 | 双模式手势以【窗口位移】判定：≤12 CSS px（`Game.dragThreshold`）= 手抖，蓄力继续、松手弹回物理基准位置；>12 CSS px = 拖窗，取消钓鱼、窗口留拖放处。`body-moved`/`body-released` 均按手势起始 scale 将物理位移转为浮点 CSS px；只以真实窗口位移判定 | 手势 |
| BR-03 | 落点映射：`rp = min(1, 蓄力×竿rangeMult)`；`targetX = 165-(165-72)×rp`，`targetY = 332-(332-312)×rp`；`distanceTiles = rp×5`。蓄力越满越远 | 钓鱼 |
| BR-04 | MAX 抛竿：蓄力 ≥ 0.999。鱼群权重 ×(1+2.2×难度/110)；垃圾率 ×0.4；宝箱概率 +0.15；结算显示金色徽章 | 钓鱼 / 结算 |
| BR-05 | 咬钩时间 600~4000ms 随机；每级最大 -250ms（Lv10 上限 1.5s）；首次抛竿 ×0.75；竿 biteMult 同步缩放 min/max；`max = max(min+200, max)` | 钓鱼 |
| BR-06 | 感叹号反应窗口 600ms；过早点击在 wait 已拦截；过晚 = 鱼逃走 | 钓鱼 |
| BR-07 | 小游戏开局对齐：绿条位置 = clamp(鱼位置 - 条高/2, 0, 568-条高)，避免开局进度狂掉 | 小游戏 |
| BR-08 | 绿条物理：按住 -1300/s²、松开 +900/s²、限速 ±300、触底反弹 vel=-30、触顶 vel=0、底边界 568 | 小游戏 |
| BR-09 | 进度条：初始 0.28；鱼在条内 +0.11/s；条外 -0.20×(0.55+0.85×难度/110)/s（diff=10 约 0.125/s、diff=110 约 0.28/s）；难度越高流失越快 | 小游戏 |
| BR-10 | 鱼难度：`diff = clamp(物种难度×jitter(0.85~1.15)×(1+0.045×等级), 10, 160)`（鱼王 Lv10≈159.5 恰好不封顶，全等级单调变难）；每局 mood 0.85~1.18 浮动游速与活跃度；diff 归一化 0~1 映射游速 46~240、变向幅度 70~185、变向间隔 720~150ms（低难鱼慢而稳、高难鱼快而狂） | 小游戏 |
| BR-11 | 宝箱：15%（+MAX/竿加成）概率，1~3s 延迟后出现在轨道 20%~80% 位置；被覆盖 +0.8/s、否则 -0.6/s，满则获得 | 小游戏 |
| BR-12 | 尺寸公式：`sizeFactor = clamp01(距离/5×(等级+2)/10×rand(90,110)/100)`；`sizeIn = floor(min+(max-min)×sizeFactor+1)`；收杆每 0.8s 出条 -1 寸（不低于 min）；非 perfect 且恰为 maxSize 再 -1 | 结算 |
| BR-13 | 品质分档：<0.33 普通 / <0.66 银 / ≥0.66 金；perfect 且初始非普通 → 品质 +1 级（银→金→铱） | 结算 |
| BR-14 | XP 公式：`(品质索引+1)×3 + floor(难度/3)`，依次 ×2.2（宝箱）→ ×2.4（完美）→ ×5（传说），每步向下截断 | 结算 |
| BR-15 | 等级阈值 XP_LEVELS=[100,380,750,1280,1750,2250,2750,3250,3750,4750]，上限 L10；鱼竿 Lv3/Lv6/Lv9 自动解锁 | 成长 |
| BR-16 | 垃圾：`chance = max(0.05, 0.2-0.015×等级)`，MAX 抛竿 ×0.4；垃圾不触发小游戏，直接结算固定 3 XP | 钓鱼 / 结算 |
| BR-17 | 存档：localStorage key `fishing-codex-save-v1`；JSON 损坏或 version≠1 → 回退默认档；加载时与默认值合并 | 存档 |
| BR-18 | 点击穿透：指针位置未知时保守保持可交互；热点 = 人物矩形外扩 10px 预热 / 工具按钮半径+10 / 钓鱼中 / 任意弹窗；仅在状态翻转时发 IPC（不逐帧抖动） | 穿透 |
| BR-19 | `#pet-hit` 层仅在 idle/charge 且无弹窗时可见；cast/wait/hook/minigame/result/弹窗期间必须隐藏（否则吞掉小游戏按住/咬钩点击/菜单点击） | 手势 / 弹窗 |
| BR-20 | 退出策略：窗口 close 事件一律改隐藏；真退出仅托盘「退出」/工具菜单「退出」（forceQuit）；单实例锁防多开；渲染崩溃自动 reload | 窗口管理 |
| BR-21 | 身体 `mousedown` 先开始 charge，再发单一 `body_drag_begin`；Rust 记录物理窗口基准及起始 scale，释放状态锁、确认左键仍按住后才 `win.start_dragging()`。不使用 CSS drag、`data-tauri-drag-region` 或逐帧 `setPosition`，不由默认 drag 属性双击最大化 | 手势 / 桥接 |
| BR-22 | `pointer-init`/`pointer-move` 为 `(GetCursorPos - inner_position) / 当前scale` 的浮点 CSS 逻辑坐标，与 DOM `clientX/Y` 同单位；窗口保存和 snap-back 坐标继续使用物理像素 | 穿透 / 桥接 |

| 风险ID | 风险描述 | 风险等级 | 应对措施 |
|--------|----------|----------|----------|
| R-01 | 原生拖拽无阈值行为、mouseup 被吞、透明窗拖影等 GUI 真机行为沙箱不可验证 | 高 | 原生按键轮询补发松开（Tauri 不以 2.5s 超时推测）；交付明确标注「未实机点测」；真机回归清单见 3.4/3.5 |
